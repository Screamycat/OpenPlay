# OpenPlay Theme Starter Template

This folder is a ready-to-test template for creating custom themes for OpenPlay.

## How to Test This Template in OpenPlay:
1. Select all files in this folder:
   - `theme.json`
   - `theme.css`
   - `icon.svg`
   - `screenshot_1.svg`
   - `screenshot_2.svg`
   - `screenshot_3.svg`
2. Right-click and choose **Compress to ZIP file** (name it `starter-custom-theme.zip`).
3. Open **OpenPlay**.
4. Open the left sidebar and click **Themes**.
5. Click **Import Theme (.zip)** and select your `starter-custom-theme.zip`.
6. OpenPlay will unpack and validate the package, and it will immediately appear in your Themes gallery ready to apply or customize!
