# 🎮 OpenPlay v0.1.0 — Initial Preview Release

OpenPlay is an open-source, offline-first cross-platform game library manager and launcher engineered for modern PCs and handhelds. Built on **Tauri v2 + Rust + React 19**, OpenPlay provides a blazing-fast, lightweight sanctuary for your entire game collection without unnecessary bloat.

---

### ✨ Key Features & Capabilities

- **Adaptive Split-View Desktop Mode**: Beautiful 7-column poster grid with live game details showcase, backdrop hero art with faded glass masking, and clear logo support.
- **Hardware-Accelerated Animated Covers**: Native, fluid playback for WebM, MP4, APNG, and GIF animated covers.
- **1-Click Library Integrations**: Automatic scanning and account linking for Steam and Epic Games libraries.
- **SteamGridDB Asset Browser**: Browse, preview, and apply vertical covers, heroes, transparent clear logos, and icons in real-time, complete with NSFW safety filtering.
- **In-App Patch Notes & News Reader**: Real-time changelogs and announcements fetched directly from official game studio feeds with full image rendering and rich formatting.
- **Dual Launch & Modded Play Actions**: Split 80/20 play button and right-click menu to launch games with mods, custom launch arguments, or dedicated mod managers.
- **Achievement Hunter Hub**: Integrated achievement browser with rarity tiers, completion tracking, unlock dates, and gamer score stats.
- **HowLongToBeat Completion Metrics**: In-depth playtime estimates across Main Story, Main + Extra, and Completionist runs.
- **Playnite Backup Importer**: Built-in 1-click importer for migrating playtime stats, custom metadata, and covers from Playnite `.zip` archives.
- **Custom Theme Accent & Panel Tinting**: Full aesthetic control over base panel tint shades and primary theme accent colors.
- **In-App Software Update Checker**: Automated version checking against GitHub releases with built-in changelog viewer and direct installer updating.
- **Offline-First Privacy**: 100% local SQLite storage with zero telemetry, zero tracking, and zero mandatory cloud accounts.
